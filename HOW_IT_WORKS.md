## 🔬 Технические детали

### Что такое "Tool Calling"?

Tool Calling - это способность модели вызывать функции/инструменты.

**Как это работает:**

1. **Вход:** Модель получает список доступных инструментов в специальном формате
   ```json
   {
     "tools": [
       {
         "name": "DuckDuckGoSearchTool",
         "description": "Searches the internet",
         "parameters": {
           "query": "string"
         }
       }
     ]
   }
   ```

2. **Модель думает:** "Мне нужно использовать DuckDuckGoSearchTool"

3. **Выход:** Модель генерирует специальный JSON
   ```json
   {
     "tool": "DuckDuckGoSearchTool",
     "arguments": {
       "query": "Кассиус Клей имя"
     }
   }
   ```

4. **Фреймворк:** smolagents парсит этот JSON и вызывает реальный инструмент

5. **Результат:** Возвращается модели для дальнейшего анализа

### Цикл "Thought → Action → Observation"

Это называется **ReAct Pattern** (Reasoning + Acting):

```
┌─────────────┐
│  THOUGHT    │  "Мне нужно найти информацию..."
│  (мышление) │
└──────┬──────┘
       ↓
┌──────▼──────┐
│  ACTION     │  Вызов DuckDuckGoSearchTool
│  (действие) │
└──────┬──────┘
       ↓
┌──────▼───────────┐
│  OBSERVATION     │  Результаты поиска
│  (наблюдение)    │
└──────┬───────────┘
       ↓
┌──────▼──────┐
│  THOUGHT    │  "Теперь нужно прочитать страницу..."
└──────┬──────┘
       ↓
      ...
```

Цикл повторяется до тех пор, пока:
- Агент не найдёт ответ (вызовет final_answer)
- Не достигнет max_steps (защита от зацикливания)

### Системный промпт - мозг агента

Системный промпт - это **инструкция**, которая определяет:

1. **Роль:** "Ты - исследователь"
2. **Цель:** "Найти информацию"
3. **Инструменты:** "У тебя есть поиск и чтение страниц"
4. **Правила:** "Перепроверяй информацию"
5. **Критерий завершения:** "Вызови final_answer когда найдёшь ответ"

**Плохой промпт:**
```
Найди информацию.
```

**Хороший промпт:**
```
Ты - профессиональный исследователь.
Твоя задача - найти точную информацию.
У тебя есть инструменты: X, Y, Z.
Всегда перепроверяй факты.
Когда уверен в ответе, вызывай final_answer.
```

### Max Steps - защита от бесконечности

`max_steps=10` означает:
- Агент может сделать максимум 10 действий
- Это защищает от зацикливания
- Если агент не нашёл ответ за 10 шагов, он остановится

**Пример зацикливания (без max_steps):**
```
Шаг 1: Поиск "погода"
Шаг 2: Не понял результаты
Шаг 3: Поиск "погода"
Шаг 4: Не понял результаты
Шаг 5: Поиск "погода"
...
∞: Агент работает вечно
```

## 💡 Почему это работает?

### Магия больших языковых моделей

Модель (LLM) обучена на триллионах слов из интернета.

Она "знает" как:
- Понимать вопросы
- Разбивать сложные задачи на подзадачи
- Выбирать нужные инструменты
- Анализировать результаты

**Но она НЕ знает:**
- Текущих событий (после даты обучения)
- Специфической информации о вашей компании
- Содержимого конкретных веб-страниц

Поэтому ей нужны **инструменты** (tools) для доступа к этой информации!

### Агент = LLM + Tools + Prompt

```
      ┌─────────┐
      │   LLM   │  ← Мозг (Qwen, GPT, Claude...)
      └────┬────┘
           │
      ┌────▼────┐
      │ Prompt  │  ← Инструкции
      └────┬────┘
           │
      ┌────▼────┐
      │  Tools  │  ← Возможности (поиск, чтение, калькулятор...)
      └─────────┘
```

**Аналогия:**
- LLM = человек
- Prompt = должностная инструкция
- Tools = компьютер, телефон, доступ к интернету

## 🎯 Ключевые концепции

### 1. Автономность
Агент **сам решает** какие шаги делать. Вы не говорите ему:
```python
# Плохо (вы управляете):
search("Кассиус Клей")
read_page(results[0])
return answer

# Хорошо (агент решает сам):
agent.run("Когда Кассиус Клей сменил имя?")
```

### 2. Многошаговость
Агент может делать несколько действий для ответа на один вопрос:
- Поиск → Чтение → Поиск → Чтение → Ответ

### 3. Планирование
Хорошие агенты планируют свои действия:
```
План:
1. Найти имя команды, занявшей 3 место на TI10
2. Найти состав этой команды в том году
3. Найти первый турнир этого состава
4. Вернуть ответ
```

### 4. Рефлексия
Агенты могут анализировать свои действия:
```
"Я нашёл информацию, но она противоречива.
Мне нужно проверить ещё один источник..."
```

После понимания базового агента, вы можете изучить:

1. **Разные когнитивные архитектуры:**
   - ReAct (рассуждение + действие)

2. **Память:**
   - Короткая память (контекст разговора)

3. **Специализированные агенты:**
   - Кодинг-агенты

   - Мультиагентные системы

4. **Production-ready решения:**
   - Обработка ошибок
