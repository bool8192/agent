# 🤖 AI-Агент с Hugging Face API

Это учебный проект для создания AI-агента, который может искать информацию в интернете.

## 📋 Что это такое?

AI-агент - это программа, которая может:
- Самостоятельно принимать решения
- Использовать инструменты (поиск в интернете, чтение веб-страниц)
- Выполнять многошаговые задачи
- Находить нужную информацию

## 🎯 Что делает наш агент?

1. Получает вопрос от пользователя
2. Ищет информацию в интернете через DuckDuckGo
3. Читает содержимое веб-страниц
4. Анализирует информацию
5. Возвращает ответ

## 🛠️ Установка и запуск

### Шаг 1: Получите API ключ от Hugging Face

1. Зарегистрируйтесь на [huggingface.co](https://huggingface.co)
2. Перейдите в настройки токенов: [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
3. Нажмите "Create new token"
4. Выберите "Fine-grained" (детализированный токен)
5. Дайте токену имя (например, "ai-agent-tutorial")
6. Дайте разрешения:
   - ✅ Read access to contents of all public gated repos you can access
7. Нажмите "Create token"
8. **Скопируйте токен** (он показывается только один раз!)

### Шаг 2: Установите Python

Вам нужен Python 3.8 или новее. Проверьте:

```bash
python --version
```

Если Python не установлен, скачайте с [python.org](https://www.python.org/downloads/)

### Шаг 3: Установите зависимости

```bash
pip install -r requirements.txt
```

### Шаг 4: Настройте API ключ

Откройте файл `.env` и замените `your_huggingface_token_here` на ваш настоящий токен:

```
HF_TOKEN=hf_ваш_токен_здесь
```

### Шаг 5: Запустите агента

```bash
python ai_agent_tutorial.py
```

## 📚 Как это работает?

### 1. Компоненты агента

Агент состоит из 4 ключевых компонентов:

```
┌─────────────────┐
│   LLM (Модель)  │  ← Мозг агента (Qwen 2.5 от Hugging Face)
└────────┬────────┘
         │
┌────────▼────────┐
│  System Prompt  │  ← Инструкции для агента
└────────┬────────┘
         │
┌────────▼────────┐
│     Tools       │  ← Инструменты (поиск, чтение сайтов)
└────────┬────────┘
         │
┌────────▼────────┐
│    Context      │  ← История общения
└─────────────────┘
```

### 2. Цикл работы агента

```
СТАРТ
  ↓
Получить вопрос
  ↓
Подумать: какой инструмент использовать?
  ↓
Использовать инструмент (поиск/чтение)
  ↓
Получить результат
  ↓
Достаточно информации? ──НЕТ──┐
  ↓ ДА                         │
Вернуть ответ                  │
  ↓                            │
КОНЕЦ                          │
  ↑                            │
  └────────────────────────────┘
```

### 3. Пример работы

**Вопрос:** "В каком году Кассиус Клей сменил имя?"

**Шаги агента:**
1. 🔍 Поиск: "Кассиус Клей смена имени"
2. 📄 Чтение результатов
3. 🎯 Анализ: нашёл, что он сменил имя на Мухаммед Али в 1964
4. ✅ Ответ: "1964 год"

## 🎓 Разбор кода

### Импорты

```python
from smolagents import (
    DuckDuckGoSearchTool,  # Бесплатный поиск в интернете
    HfApiModel,            # Модель от Hugging Face
    ToolCallingAgent,      # Агент с инструментами
    VisitWebpageTool,      # Чтение веб-страниц
    PromptTemplates        # Шаблоны промптов
)
```

### Модель

```python
model = HfApiModel(
    model_id="Qwen/Qwen2.5-72B-Instruct",  # Модель
    token=os.getenv("HF_TOKEN")             # Ваш токен
)
```

Qwen 2.5 - это бесплатная open-source модель от Alibaba, которая хорошо работает с инструментами.

### Инструменты

```python
tools = [
    DuckDuckGoSearchTool(max_results=5),  # До 5 результатов поиска
    VisitWebpageTool()                     # Читает текст со страницы
]
```

### Системный промпт

Это инструкция для агента. Вы объясняете ему:
- Кто он такой
- Что он должен делать
- Какие у него есть инструменты
- Как их использовать
- Когда завершить работу

### Агент

```python
agent = ToolCallingAgent(
    tools=tools,           # Какие инструменты доступны
    model=model,           # Какую модель использовать
    prompt_templates=...,  # Системный промпт
    max_steps=10           # Максимум 10 шагов (защита от зацикливания)
)
```

## 🐛 Решение проблем

### Ошибка: "Invalid token"
- Проверьте, правильно ли скопирован токен в `.env`
- Убедитесь, что токен имеет нужные права доступа

### Ошибка: "Module not found"
- Установите зависимости: `pip install -r requirements.txt`

### Агент не находит информацию
- Увеличьте `max_steps` (например, до 15)
- Улучшите системный промпт
- Попробуйте другую модель

### Агент зацикливается
- Уменьшите `max_steps`
- Добавьте в промпт четкие инструкции о завершении
